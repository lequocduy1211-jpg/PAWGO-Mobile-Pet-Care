# PAWGO Mobile Pet Care

Website concept for a mobile pet grooming service.

## Included
- Responsive HTML/CSS landing page
- PAWGO brand direction
- Hero, services, storytelling, About, PAWGO Van, gallery, reviews and booking sections
- Scroll reveal animations
- Mobile navigation
- Front-end booking confirmation interaction

## Run
Open `index.html` directly in a browser, or use VS Code Live Server.

## Next production layer
The `/admin` CMS can be added as a separate internal dashboard connected to a database so the owner can edit hero content, services, pricing, stories, gallery, reviews, vans, service areas and bookings without changing source code.
